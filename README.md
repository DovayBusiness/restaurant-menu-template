# Restaurant Menu Template

A polished, responsive restaurant website template for displaying a restaurant's story, contact information, opening hours, menu categories, dishes, descriptions and prices.

## Features

- Editorial, photo-forward restaurant design
- Responsive layout for desktop and mobile
- Side menu category selector; selecting a category shows only that category's dishes
- Catalog only: no cart, online ordering, delivery checkout, payment or forms
- Built with plain HTML and CSS; no JavaScript or build tools required

## Preview locally

Open `index.html` in a web browser. An internet connection is needed for the linked Unsplash photography.

## Customize the template

Open `index.html` and replace the sample Olive & Ember identity, introduction, menu items and prices, address, opening hours, phone, email and social links with the restaurant's details. Search for `Olive & Ember`, `Your City`, `123 Market Street`, `hello@example.com` and `(000) 000-0000` to find common placeholders.

Menu categories and dishes are in the `#menu` section. Each category has its own section (`starters`, `mains`, `sides`, `desserts`, or `drinks`). When adding a category, add a matching radio input, side-menu label, category section and CSS checked-state selector.

Prices and restaurant details are sample content; verify and replace them before using the template for a real business.
